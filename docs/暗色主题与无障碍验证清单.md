# 暗色主题与无障碍验证清单

> 范围：webapp 四个页面（总览 / 新剧预测 / 模型评估 / 数据集）的浅色 / 暗色 / 跟随系统三主题支持。
> 生成日期：2026-10-06。本文只记录**已实测**的项目；未测试项明确标注，不声称满足全部无障碍标准。

## 一、主题 CSS 结构

| 文件 | 职责 |
| --- | --- |
| `static/css/tokens.css` | 设计 token。暗色值两组入口：**`[data-theme="dark"]`**（手动）与 **`@media (prefers-color-scheme: dark)`**（未手动指定时跟随系统），内容保持同步；`color-scheme` 同步切换 |
| `static/css/base.css` | 骨架引用 token（背景纹理点、毛玻璃顶栏、阴影）；`:focus-visible` 焦点环；`prefers-reduced-motion` 全局降级 |
| `static/css/components.css` | 组件全部走 token；verdict/badge 底色用 `--c-tint-*`；加载态 `.btn.is-loading`；禁用态光标；主题菜单样式 |
| `templates/base.html` | `<head>` 内联脚本首帧前应用主题（防 FOUC）；优先级 `?theme=` > localStorage > 跟随系统 |
| `static/js/theme.js` | 三态切换菜单（details + radio，原生键盘可达）、localStorage 持久化、系统主题变更监听、广播 `themechange`；显式选择后清除 `?theme=` 预览参数 |
| `static/js/charts.js` | 图表配色不再硬编码：`make()` 前从 CSS 变量解析当前主题 token；`themechange` 时销毁并调用页面注册的重建回调 |

## 二、暗色对比度验证（WCAG 2.1 AA）

方法：`webapp/tools/contrast_check.py` 按 WCAG 相对亮度公式计算。所有文字对均按**普通文字 4.5:1** 从严（未按大号文字 3:1 放水）。

| 文字 | 背景 | 比值 | 结论 |
| --- | --- | --- | --- |
| `#fafafa` 主文字 | `#09090b` / `#131316` / `#1a1a20` | 19.06 / 17.77 / 16.59 | ✅ |
| `#a1a1aa` 次要文字 | `#09090b` / `#131316` / `#1a1a20` | 7.76 / 7.24 / 6.76 | ✅ |
| `#8e8e99` 弱化文字 | `#09090b` / `#131316` / `#1a1a20` | 6.14 / 5.72 / 5.34 | ✅ |
| `#7aa2f7` 品牌色 | `#09090b` / `#131316` | 7.90 / 7.36 | ✅ |
| `#7aa2f7` | accent-weak 混合底 ≈`#202633` | 6.01 | ✅ |
| `#0a0a0c` 反色文字 | 品牌色底 `#7aa2f7`（按钮/chip） | ≈7.9 | ✅ |
| 分档红 `#e8604c` | `#131316` / tint `#2a1715` | 5.48 / 5.04 | ✅ |
| 分档橙 `#e5a04b` | `#131316` / tint `#261c10` | 8.36 / 7.53 | ✅ |
| 分档灰 `#9aa3b2` | `#131316` / tint `#1d1d24` | 7.29 / 6.59 | ✅ |
| 分档绿 `#4eb598` | `#131316` / tint `#0f211c` | 7.41 / 6.68 | ✅ |

唯一未通过项与处置：白字压浅色渐变按钮中点仅 3.07:1 → 暗色模式改为**深字 `#0a0a0c` 压亮渐变**（≈7.9:1）。

## 六、遗留与限制（如实声明）

1. **未做屏幕阅读器与纯键盘全流程实测**，第五节的两项标 ❌；本文不声称满足全部无障碍标准。
2. 图表数据系列色（红/橙/绿等）在暗色下用于**图形元素**（柱/点/线），非文字，不受 4.5:1 约束；tooltip 文字配色已验证。
3. 暗色 token 两组入口（`[data-theme="dark"]` 与媒体查询块）为**重复代码**，后续改色必须两处同步（文件内已注释提醒）。
4. `?theme=` 参数用于分享/预览，不写入存储；用户在菜单显式选择后参数被清除。
5. 未验证 Windows 高对比模式（forced colors）下的表现。
